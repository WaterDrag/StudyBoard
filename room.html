Sdílet místnost

Pošli tento kód spolužákovi. Připojí se jako prohlížeč – oprávnění lze změnit v sekci Členové.

------

Kód je platný do smazání místnosti.

Kdo otevře odkaz, rovnou se připojí. Editora může získat jen přítel vlastníka — ostatní se připojí jako prohlížeč. Host (anonym) má členství vždy max 1 hodinu.

ℹ️ Pozvánky s právem editora může vytvářet jen vlastník místnosti.

–

Agent nepotřebuje být členem místnosti ani přítelem. Přístup dostane přes API podle oprávnění tokenu. Token se ukáže jen při vytvoření; ulož ho do soukromých přihlašovacích údajů agenta.

Token — zobrazí se znovu jen po vytvoření nové pozvánky
Kdo získá token, může použít přidělená oprávnění. StudyBoard neumí nezávisle ověřit, zda je jeho držitel opravdu AI.

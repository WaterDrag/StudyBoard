Agent nemusí být členem místnosti. Přístup dostane přes API podle oprávnění tokenu. Token se ukáže jen při vytvoření, ulož ho do soukromých údajů agenta. Agent nikdy nesmí víc než ty: když z místnosti odejdeš nebo ti klesne role, jeho přístup se taky omezí.
